# Project Roadmap

## Phase 1 - Starter AI Pipeline

Muc tieu:

- Co sample CSV.
- Co preprocessing.
- Co sentiment baseline theo rating hoac model ML don gian.
- Co aspect detection bang keyword.
- Co analytics va insight template.
- Co API de backend goi.

## Phase 2 - Train Model That

Muc tieu:

- Thu thap dataset lon hon.
- Train TF-IDF + Logistic Regression.
- Tao report metric.
- So sanh them Naive Bayes va SVM.

## Phase 3 - Dashboard Integration

Muc tieu:

- Backend upload CSV.
- Backend goi AI service.
- Frontend hien thi dashboard.
- Export CSV/PDF neu kip.

## Phase 4 - LLM Insight Layer

Muc tieu:

- Chi dung LLM de viet insight, summary, recommendation.
- Khong dung LLM de lam toan bo pipeline.
- Prompt phai dua tren so lieu da tinh.

## Phase 5 - Nang cap sau demo

Co the phat trien:

- Domain-aware aspect theo nganh hang.
- Vietnamese sentiment model.
- BERT/DistilBERT.
- Real-time review monitoring.
- Alert khi negative spike.
- Suggested reply cho khach hang.
- Competitor analysis.
